- **Визуал:** Панель кнопок на сайте снизу карточки товара кофемашины, кнопки имеют разный вид и размер (на слайде момент анимации)

- **Выбор:**
    1. (1) Оставить как есть, но замедлить скорость анимаций
    2. (3) Заменить анимации на простые иконки рядом с текстом кнопок
    3. (5) Убрать все анимации, оставив только изменение цвета при наведении для всех кнопок. Отдельно выделить кнопку «Купить»
    4. (4) Сделать одну одинаковую плавную анимацию изменения фона для всех кнопок, но для «Купить» добавить едва заметную пульсацию тени
    5. (1) Удалить все кнопки кроме «Купить»

- **Jippy:** Имитация работы... Это попытка лечить симптомы, а не болезнь.

- **Jippy:** Ха-ха, меркантильненько, но может быть эффективно для бизнеса. Дизайнеру не стоит удалять уже реализованный функционал

#### Слайд 4
- **Визуал:** Три карточки товаров (на каждой фотография кофемашины, описание, цена, и кнопки внизу из предыдущего слайда) карточки находятся криво друг от друга, также и элементы на карточках: цены, описание, текст и картинки
- **Jippy:** 
    - Элементы страницы, картинки кофемашин, описания, цены, карточки товаров плывут, расположены неровно относительно друг друга.
    - Совсем нет ощущения порядка и структуры. Поэтому я предлагаю верстку по сетке — это основа визуальной разработки.
- **Выбор:**
    1. (3) Упростить: расположить товары не в строку, а в один столбец друг под другом
    2. (2) Выровнять все вручную, задать каждому элементу фиксированные отступы (margin) в пикселях
    3. (4) Использовать CSS-свойство `display: flex` для контейнера, которое автоматически будет выравнивать элементы по центру
    4. (1) Это не баг, а фича — развиваем визуальное мышление пользователей
    5. (5) Включить для контейнера с товарами CSS-свойство, где каждые элементы будут внутри невидимой сетки `display: grid` с заданными колонками и отступами.

##### Ветка 1
- **Jippy:** Тактическое отступление. Если не получается с сеткой, можно упростить макет. На мобильных устройствах это даже будет смотреться хорошо. Но для десктопа это не лучшее использование пространства.
